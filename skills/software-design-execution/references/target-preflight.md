# Target Preflight

Read this before source edits when the workpack has `PSEAM-NNN` entries or a protected `implemented-evolution`. It rechecks the frozen inventory and physical seams Stage 9 recorded against the real target.

## Frozen Inventory

Reconstruct the inventory Stage 9 recorded: the selected slice, its direct and transitive implementation, build, and verification prerequisites, protected changed interfaces, mechanically known direct consumers, required effectful commands, and directly affected implementation surfaces. A direct-dependency addition needs a concrete import, manifest, lock, generator, generated output, fixture, test, verifier, command-call, or exact-identity edge from an existing item.

Run every safe independent probe; a failed prerequisite blocks only its dependent probes. Group failures by canonical root cause with their affected probes and slices. After repair or resume, rerun the same inventory from its beginning and require zero new blockers. Report a genuinely new item, with its previously unavailable direct edge, as a readiness-process defect.

## Shipped Seams

Each probe reaches the shipped export, built entrypoint, public route, artifact reader, application mount, or operator command the workpack names. When this slice creates or changes the producer, run the candidate-fixture or current-consumer preflight now and leave the built producer-consumer proof to its scheduled `VE-xxx`; the selected output's absence before implementation is expected.

## PSEAM Recheck

For each `PSEAM-NNN`, confirm that observations, implementation situation, boundary class, candidate proof and provenance, change-impact closure, and required-command effects still match the handoff. A protected `implemented-evolution` needs its focused candidate run against the real existing consumer. Confirm every required change is writable by a `Target` and every required command effect stays inside a named `PB-xxx`. When an observation moved, a new incompatible dimension appears, or a delta belongs to an `Existing prerequisite` or omitted surface, finish the safe checks and route one consolidated contradiction to Software Design.
